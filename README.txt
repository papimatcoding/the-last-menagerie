THE LAST MENAGERIE — DIRECTOR'S CUT

Estructura:
- index.html
- css/game.css
- js/data.js
- js/game.js
- assets/creatures/*.svg

Uso en TrebEdit:
1. Extrae la carpeta completa.
2. Abre la carpeta como proyecto.
3. Abre index.html.
4. Usa Preview / Run.

No necesita Internet ni librerías externas.
No cambies la estructura de carpetas salvo que actualices las rutas relativas.

Cambios principales:
- Perder un combate termina la run inmediatamente.
- Mapa ramificado procedural nuevo en cada run y cada Acto.
- 28 criaturas con ilustraciones SVG separadas.
- 9 tipos de nodo + Guardianes.
- Sangre/Huesos explicados y garantizados desde la mano inicial.
- Cartas con memoria, Despertares, Heridas e Injertos.
- Interfaz de deck, detalles de Sigilos y textos más sobrios.
